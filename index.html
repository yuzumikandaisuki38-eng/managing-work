CMを作る

用意した背景画像・オリジナルBGM・毎日のワクワクメッセージを組み合わせたCMを生成できます。 作成後は必ず内容を確認してから、手動で公開してください。

GitHub Actionsから作成

リポジトリのActions画面で「Review daily CM」を開き、「Run workflow」を押します。 完了後、Artifactsからレビュー用ファイルをダウンロードできます。

GitHubでCMを作る

ターミナルから作成

日付ごとに変わる、前向きでワクワクするメッセージをCM内で3行に分けて表示します。

ここで入力した文字がCM画像に反映されます。Canva等で編集する場合も、この文字設定を元データとして利用できます。

添付された7種類の画像から背景を選べます。画像はリポジトリ内で管理し、外部URLは使用しません。

このCM生成機能はPC上で実行します。SNSへの自動投稿は行いません。

cd /Users/hidemitogo/.copilot/repos/managing-work
python3 cm_generator/generate_cm.py --output-dir generated

公開用CMファイルをブラウザからそのままダウンロードできます。ファイルを確認してから、各SNSで手動投稿してください。

Canvaで文字を調整する場合は、生成された「*_canva_editable.svg」をCanvaへアップロードしてください。背景と文字要素を分けた編集用素材です。

このページからSNSへ自動投稿することはありません。画像・音声・文面を人が確認してから手動で公開してください。
